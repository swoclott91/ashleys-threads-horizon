# Ashley’s Pro: product description draft (for review)

Status: **draft, not applied.** The live product (`ashleys-threads-pro-membership`) has not been
changed. After approval, paste the HTML below into the product’s description in Shopify admin.

The Pro PDP template doesn’t render the product description on the page (the hero and sections
carry the content). The description still shows in search results, shared links, Google Shopping,
the cart and order emails, so it should match the page.

Figures are today’s program values (Theme settings › Membership). If the fee, Threads Cash rate or
shipping credit changes, update this text by hand: product descriptions can’t read theme settings.

## Copy

**Make more. Keep more.**

Ashley’s Pro is an annual membership built for apparel sellers, decorators, and makers who want
more value from every order.

For $79 a year, unlock exclusive Pro pricing, earn 2% back in Threads Cash on eligible purchases,
and receive up to $15 off shipping on one qualifying order each month.

Your Pro benefits include:

- Exclusive Pro pricing on eligible products.
- 2% back in Threads Cash.
- Up to $180 in potential annual shipping savings.
- All the personalized shopping and ordering tools included with your free Ashley’s Threads
  membership.

Better prices. Better margins. More room to grow your business.

One payment provides 12 months of Pro membership benefits.
